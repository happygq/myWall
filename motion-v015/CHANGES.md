# 《远行客》V0.15 — 纯净星空背景

本轮只替换 V0.14 的 Canvas 背景。其余人物年龄事件、轨迹、关系距离、升星预备、星座拓扑、圆体字卡、六人升星参数面板及 Web Audio 配乐均保持原样。

## 视觉依据
使用此前确认的无前景、无标签的纵向星空参考图。背景保留接近黑色的深蓝底色、右上角小范围的低亮度暖蓝星云，暗星数量很少且分布不均匀。画面下半部没有星云，避免与人物尾迹争夺注意力。

## 实现
- 从参考图裁切至 440:858 的逻辑画布纵横比，保留右上方星云主体。
- 背景优化为内嵌 JPEG，HTML 可以独立运行，不依赖外部图床或网络请求。
- 动画只在每帧最底层绘制这张静止背景，不添加新的点状星星、噪声纹理或云层。
- 图片未加载前采用深蓝黑底色作为回退。
- 文件仍为 V0.14 的完整交互版（不是静态渲染）。
- GitHub 预览分支：renjian-preview-20261030；未更改 main。

## 验证
本地 Chromium 已检查 60 岁和终章帧、人物与孩子间距、字卡切换及 JavaScript 错误。在线托管地址需要在目标设备浏览器中实际确认。
