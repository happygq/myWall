# 《远行客》V0.12｜关系距离、单色字卡与配乐精修

## 阶段状态

可交互视觉与音色比较版，六位亲人的升星年龄仍可调，未锁定最终剧情与配乐。所有数值使用 440×858 逻辑画布坐标。

## 1. 已实施的运动修改

- 伴侣从左侧入场的路径算法、入场时间与运动持续时间不变；并肩目标坐标从 x=187 调整到 x=201。主角 x≈230（有少量独立漂移），稳定距离约 28–30 坐标单位。两人过近时，仅把“我”的姓名标记移到光点下方，保留两颗光点本身的距离。
- 孩子依旧从家庭中心出生，60 岁（指主角年龄）时横向距离由 110 改为 **85**。采用连续 ease 插值，不出现轨迹截断、瞬移或单独飞跃曲线。结尾仍使用同一条连续近垂直尾迹。
- 六位亲人升星年龄的原有参数面板、三组预设、升星流程和 B 型星座拓扑不变。

## 2. 单色字体系统（新设计）

- 字色唯一：`#E5E7E9`，在同一颜色上使用不同的透明度表现信息层级。删除金色强调、印章、框线、光圈、描边、阴影或文字背景色块。
- 背景沿用既有深蓝黑星空，不额外加背景遮罩。星座、人物仍使用原本柔和的角色识别色；**“单色”限制仅针对结尾文字**。
- 主标题宋体方向：iOS 使用 Songti SC，Windows/Android 用可用的 Noto Serif CJK SC 等回退；小字用宋体或 PingFang SC。没有捆绑字体文件。
- 所有方案固定文案为：标题「远行客」、引句「人生天地间，忽如远行客。」（《古诗十九首·青青陵上柏》）、原创收束「相逢曾同路，星光伴远行。」。通过版式比较，避免同时改变文案和排版。

## 3. 原创配乐优化

- Web Audio 的钢琴音色使用较软的正弦基频、极低二次泛音、较低低通截止频率（1200Hz）、较慢起音（约 105ms）与更柔和的指数衰减（约 3.45s），音量从原来的约 .085–.14 降至约 .039–.058。
- 弦乐风格铺底的低频层与慢起音更加突出，且音乐主混音避免提前过响；这些是原声音色合成，而非真实录制弦乐。
- 收尾使用与 D 调性具有稳定开放五度关系的 **A4 / 440 Hz 长音**（仅附极轻的同音八度泛音，并非叠加另一个旋律音）；约 0.72 秒渐入、随后缓慢指数衰减，历时约 9.15 秒（网页版本）。
- 收尾触发参考「我完成升空」以及「最后一位亲人完成升空并开始形成星座」的动态较晚者。它随六位亲人的年龄参数自动变化，但网页实时音频不是逐帧锁定的电影混音。
- MP3 是使用默认年龄方案的**离线原创合成试听**（128.5秒）；与浏览器的实时音乐使用相同方向，但配器细节及结尾长度有差别。它不会跟随用户调整升星时间。

## 4. 本次测试

- 本地 Chromium 中四种末尾版式、角色位置、人物年龄预设切换和播放控制均能运行，未出现脚本异常。
- 主角年龄 60 时，Son–Me 横向距离约 85，伴侣–Me 约 27.9，动态尾声经修改参数后也能重新计算。
- Web Audio 需用户点击才可开启；在 Chromium 中确认最终长音事件只触发一次。实际 Safari 的浏览器音色、音量及手机扬声器表现尚待实机评估。

## 5. 下一步审美裁定

建议在同一个固定星座完成的瞬间比较 A、B、C、D 四套版式。先比较信息布局，再判断是否需要精简原句或改写第二句。正式成片只保留一套字幕，并进一步将字幕淡入节奏与长音尾声进行同步混音。
