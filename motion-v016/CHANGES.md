# 《远行客》V0.16 — 人物称谓固定锚点

## 修改目标
消除 V0.15 入场、滑出、升星准备以及升星过程中姓名的垂直跳跃。

## 技术原因
旧版会逐帧扫描人物光点之间的水平距离，遇到名字接近时把标签从上方挪到下方（或反之）。主角的标签也根据伴侣的接近情况触发上下换行。

## 修复
- 使用每个人物固定的 `LABEL_ANCHORS`（`dx,dy` 逻辑画布单位）。
- 标签始终跟随所属光点，不再基于其他人物位置进行动态避让。
- 同行、侧向离场、去世准备、升星与成为静止星点，都复用 `identityLabel` 和同一锚点。
- 通过事先设计的固定高低层错开同桌、发小、初恋、高中同窗、大学同窗、同事与核心家庭的标签。
- 保留原先的角色轨迹、年龄时间参数、升星/星座、125 秒配乐方向、V0.15 星空背景、六人参数面板和结尾排版。

## 回归验证
- 本地 Chromium：自动播放、暂停、切换中文命名预设、结尾字卡、升星时间预设、音乐开关正常，未发现 JavaScript 错误。
- 三套中文命名方案（亲切日常/诗意/轻网络），共抽查约 570 个年龄状态，标签矩形扫描未发现相互重叠（只统计当前画面内已绘制文本；不能保证在所有连续时刻绝对不重叠）。
- 各类状态变换（入场、侧滑、准备远离、升星、星点）对比了 41 个状态样本，标签相对于光点的偏移保持一致。
- 主角60岁时子女间距仍为56逻辑单位。
