# 《远行客》V0.14 — 微光星空与关系距离

## 修改范围

本轮仅实施三项定向调整，基于 V0.13，未修改六位亲人的升星年龄参数面板、升星预备机制、星座拓扑、结尾文案、圆体字卡、配乐、画布规格或总播放速率。

### 1. 同事同行时长减半

- 首次加入：主角年龄 `23.8` 岁（不变）
- 开始侧向离场：从 `38.8` 岁改为 `31.3` 岁
- 人物关系标示持续时间：由 `15` 年缩至 `7.5` 年
- 侧向滑出动画持续时间 `2.2` 个叙事年龄单位与原飞行曲线保持不变。因此完全离开画面约在 `33.5` 岁。

### 2. 孩子成年独立距离

- 主角与伴侣在典型同行年龄的横向间距约为 `28` 个 440×858 逻辑画布单位。
- 孩子在主角 60 岁及以后相对于主角的水平目标距离由 `85` 调整为 **`56`**，即约两倍伴侣间距。
- 仍使用既有渐变函数从出生时的位置连续过渡，不增加横向突变；结尾穿越星座时沿原有近垂直生命轨迹前进。

### 3. 克制的星空背景

- 背景为预渲染 Canvas 纹理：深蓝黑底色、跨越整幅画面的极淡斜向星云、低亮度微小星尘，带轻微暗角。
- 背景星点均无星芒，无强发光，且在亮度和尺寸上显著低于人物光点。
- 背景一经生成便保持静止，不引入闪烁/流动等可能抢夺叙事注意力的动画，同时减轻移动设备每帧渲染负担。
- 不使用外部图片、字体或网络资源；可作为单文件 HTML 在完整浏览器中运行。

## 回归测试

- 在本地 Chromium 页面中，V0.14 无 JavaScript 异常，拖动年龄/重播按钮可操作。
- 主角 60 岁：伴侣相距约 `27.86`、孩子相距 `56.00` 个逻辑单位。
- 同事：起始 `23.8`、离场开始 `31.3`。
- 两类人物离场（侧滑/升星）、亲人升星参数与音乐结构均沿用 V0.13。

**说明：** 出场和离场数值仍表示主角的年龄。六位亲人的升星时间仍可在参数实验室中调整，尚未冻结。
