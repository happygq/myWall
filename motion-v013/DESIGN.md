# 《远行客》V0.13 — 圆体、升星预备与五声配乐

**定位：** 高保真运动研究版。原视频作为运动与情绪参考；代码和旋律均为本项目原创，不是原作者工程或配乐的复制。

## 1. 字体

- 全部人物中文标签、结尾四套版式优先使用系统圆体 `Yuanti SC / STYuanti`，其他环境逐级回退到圆润无衬线字体。字卡保持单色 `#E5E7E9`，仅字号、字距、透明度变化。
- 不依赖外部 CDN 或字体文件；不同系统字体的最终形态可能不同。需要在 iPhone Safari 上再次检查。

## 2. 升星：三段式无跳帧过渡

- **准备（PREPARING）**：升星设定年龄前约 2.5 个主角年龄单位，人物在 `Y=534` 同一横线中缓慢横向偏移，平滑到预设偏移位置；原轨迹连续生长。
- **离开现实（ASCENDING）**：到用户设定的升星年龄时，现实线停止向上生长，原光点从相同坐标起步；保留 0.55 单位停顿后，用约 5.45 单位缓慢升空。
- **成星（STAR）**：到达固定星座节点后保持静止；星座 B 四星闭环＋祖辈双翼延伸不变。

准备偏移量（画布坐标单位）：外婆 -23、爷爷 +24、爸 +30、妈 -29、伴侣 -39、我 -14。偏移不改变配置中的升星年龄。孩子的独立坐标改为参考“我”的常态轨迹，避免我准备离场时把孩子也带走。

## 3. 配乐

- **原创五声钢琴**：D 大调五声音阶 **D、E、F♯、A、B**，构成数组稀疏变化的原创动机；不是原视频旋律的逐音转写。音量低于弦乐，起音较柔和，衰减长；低通控制高频。
- **柔和弦乐**：使用低密度持续和声；在“我”完成升星后逐渐开放至 D(add9) 色彩，和声层数、音域与亮度缓慢增加，而不是突兀高音冲击。
- **最后尾音**：默认组合下，在星座成形后约 4.2 单位出现轻柔 A4，约 9 秒衰减；六位升星时间更改后，网页会相应重算尾音触发时机。
- MP3 参考版为默认升星参数约 125 秒的离线导出。网页 Web Audio 是使用同一音乐方向的实时合成版本，音色和混音略有差异。
- 自动播放限制：须点击「♫ 开启配乐试听」。

## 4. 保持不变的基线

- 六人升星年龄依然由 V0.11 参数面板控制；没有提前锁定伴侣从 75 到 81 的建议。
- 相遇、侧滑离场、孩子出生、孩子成年与“我”距离 85、伴侣与“我”约 28 的横向关系维持不变。
- 年龄轴、下移后的 Y=534、B 星座的坐标与拓扑、结尾孩子沿同一轨迹穿越星座、单色四套字卡布局保持不变。

## 5. 浏览器验证

本地 Chromium 进行了 73.3 岁 PREPARING、75.7 岁 ASCENDING、81.5 岁 STAR 的连续状态检查；改变年龄预设后星座顺延；声音开关、页面播放控制以及圆体字卡的页面渲染未出现 JavaScript 报错。**外部托管域名及 iPhone Safari 尚未实测。**
