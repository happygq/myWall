# 《人间一程》高保真复刻蓝图 v0.2

**状态：** Motion Core / first working prototype  
**依据：** 用户上传的原作 82 秒录屏、分时截图，以及本轮确认的两类离场规则。  
**目标：** 先复刻极简动态视觉语言，不引入中国风视觉元素；以后仅替换角色、事件与结尾文本。

## 1. 视觉不变量

1. 一个共同的“现在”：所有正在同行的光点均位于相同的屏幕 `headY`，区别只在水平位置；年龄轴与历史轨迹相对于 `headY` 平滑移动。
2. 关系靠位置表达：`我`居中，伴侣紧邻，孩子从二人之间诞生并逐渐独立；父母再向两侧，朋友按照关联靠近。**不绘制亲属关系连接线。**
3. 线条是历史运动轨迹而非图表装饰：连续、极细、软光、从近到远渐暗渐细、老段略微飘忽；亮度上不压过人物光点。
4. 入场从左/右画外飞入，弧线必须至少位置和一阶导数连续；过渡最终朝向竖向随行，不能出现硬折。
5. 不同行的退出是沿同一年龄线向左/右滑出，而不是升星；去世则停止现实轨迹的延续，然后离开时间轴向上缓慢升空成为持久的星。
6. 背景是低对比度近黑蓝星空；大留白；前期无标题、无诗句、无山水、无边框、无大光效；结尾才出现文字。

## 2. 运动坐标系

- `t`：当前叙事年龄，单位年，连续，可拖动。
- `headY`：正在同行的所有人物当前水平基准线，固定于视口高度约 46–50%。
- `ageY(a,t) = headY + (t-a) × pixelsPerYear`：历史节点年龄 `a` 对应当前屏幕位置。`a<t` 在下方；未来在上方。
- `x_i(a)`：人物 `i` 在年龄 `a` 时的横向位置；所有轨迹都是它的运动历史。
- 人物沿年龄轴的共同时间推进不等同于他们自身年龄。人物的 `enterAge`、`leaveAge` 都以主角年龄为参照。
- 画面结束前保留全局单调的年龄推进；拖动应以纯函数重新绘制，能任意回放与复现。

## 3. 角色状态机

`NOT_ARRIVED → ENTERING → COMPANION → {DRIFTING_OUT | STOPPED_FOR_STAR}`

- `ENTERING`：头始终位于现在的 `headY`，从画外水平位置以平顺曲率靠向目标位置。
- `COMPANION`：头继续共享 `headY`，只有非同步、小振幅水平微动。
- `DRIFTING_OUT`：头继续共享 `headY`，横向越界；退出完成后头不再显示，最后一段历史轨迹在视口滚动中自然消失。
- `STOPPED_FOR_STAR`：在 `deathAge` 截断现实尾迹，光点脱离时间线，沿单独的柔和上升动画升向天空。
- `STAR`：星点维持在天空固定坐标上，轻微闪烁，直到结尾。与现实轨迹彻底分离。

`DRIFTING_OUT` 与 `STOPPED_FOR_STAR` 不允许合并为同一通用 exit 效果。

## 4. 过渡方程

- 侧边飞入 / 向外离场使用五次 smoothstep：`S(u)=6u⁵−15u⁴+10u³`，使两个端点的速度与加速度为零；由年龄驱动，适合无接缝回放。
- 可叠加非常微弱、事件内衰减的横向弧形偏移，形成不完全机械的长弧。
- 常态水平微动使用几个低频、不同相位的小幅正弦分量；振幅通常不超过线条间隔的 10%，避免同步机械摆动。
- 历史尾迹采样年龄间隔建议 `0.07–0.12` 年，Canvas 分段绘制不同 alpha/宽度；须保证头附近最亮、最粗，历史端单调减淡、减细。
- 离世升空采用独立的平滑上升函数；死亡后的现实轨迹长度冻结，但其位置仍随年龄轴下滚。升空路线的暂态细线渐隐，不应被误读为时间轴继续生长。

## 6. 实施原则

- 首个可交互版本：一个离线、自包含的 HTML 文件；只使用 Canvas2D / 原生 JS；不加载 CDN、字体或图片。
- Browser Safari/Chrome 经 HTTPS 打开（`sandbox` 文件预览不是合适的运行环境）。
- 支持播放/暂停、重播、任意年龄拖动、速度控制；在 UI 显示当前年龄；支持触控。
- `render(t)` 尽量为确定性函数：同一年龄应得到可重复的结构画面，不依赖上一帧积累的状态。
- 后续导出 MP4 使用固定步长渲染，尽量不重新实现另一套动画逻辑。

## 7. 验收门槛

1. **零空白**：Safari/Chrome 页面首次载入显示画布、自动播放，按钮可响应；脚本失败有明确提示。
2. **共同现在**：所有处于同行状态的人物光点在水平线的 `±1 px` 范围内；入场与横向离场也不脱离该时间线。
3. **离场分型**：至少 1 位朋友向外漂离 + 1 位亲人升星；两者在进度拖动前后逻辑一致。
4. **曲线连续性**：所有入场/离场采用平滑曲率，不能肉眼发现硬折、明显瞬时速度跃变。
5. **亲疏布局**：夫妻最近，孩子从中心出生并向外发展；父母比核心家庭稍远；不得出现角色名字长期重叠。
6. **线条克制**：头部亮，历史渐暗；背景与大光效不得压过线条；避免明显粒子爆炸。
7. **结束收束**：记忆星辰留存，终幕才出现简短文案。

## 8. 下一轮评审焦点

本轮只审 4 项：**A)** 人物入场与退场弧线；**B)** 轨迹的粗细/透明度/飘忽；**C)** 同一时间线与亲疏布局；**D)** 升空成星的情绪节奏。暂不评中国文化风格或最终文案。
