# 《人间一程》V0.7 — 空间、人物事件与视觉系统设计评审

**阶段：** Motion Study V0.7（空间基线已实现，角色事件仅评审不修改）  
**依据：** 上传的原作录屏与截图、V0.6 交互引擎、此前确认的升星/侧滑离场规则。  
**身份：** 一部虚构人生的示例叙事，不是对普遍人生路径或真实家庭成员年龄的主张。

## 一、已应用的空间改动与检查

- 固定逻辑画布 **440 × 858**。全体仍在同行的人物共享同一当前年龄水平线，由 **Y=414 → Y=534**，向下移动 **120 逻辑像素**；画面高度占比从 48.3% 变成 62.2%。
- **时间比例 APY=33**、所有角色的 start/exit/death 数值、人物相对横向间距、入/离场弧线公式均保持原样。
- 既有星座静止坐标保持原样：外婆 (80,113)，爷爷 (389,86)，父亲 (326,180)，母亲 (115,235)，伴侣 (181,287)，我 (221,342)。
- Son 结尾继续遵循原路径的纵向位移，额外向上补偿 120 逻辑单位：由旧 373 改为 493；没有再生成独立的横向飞行弧线。在 60 岁后的同行阶段，Son 与 Me 水平间距依旧是 **110 逻辑单位**。
- 代价：因为当前水平线下移、年龄比例保持 33 px/年，屏幕下方同时可见的历史轨迹长度由约 13.5 年收缩至约 9.8 年。这是有意保留“上方记忆空间”所造成的布局取舍；若要加长尾迹，应在下一轮单独审议 APY，不能顺便改动时间含义。
- 亲人升星仍使用原来的叙事时间长度；由于起始位置下移、终点不变，屏幕中的上升距离变长，视觉速度会略高于上一版。后续需要在真实播放中对照此前确立的“气球慢升”标准审阅，不应误称速度完全不变。

## 三、终章排版审查

### 推荐方案 A：**中下部的两级文字层级**（V0.7 试用）

- 星座固定在上半部（最低一颗星 y=342）；Son 在右侧近垂直穿越，上方舞台保持不遮挡。
- 中文标题 **“人间一程”**：中心 x=220，y=511，字号约32px，宋体/现代宋体系列，颜色柔白，不加高亮光圈。
- 两行结语位于 y=555、581，字号15px，思源黑体/PingFang SC 类无衬线；两行间距26px，文字低于标题一个视觉层级。
- 让文字在星座连线基本完成时（动画时间约95.9）才开始柔和淡入，避免与“自我升星”同时抢夺注意力。
- 原结语暂不改内容：**有人陪你走过一段路。/ 有人化作星辰，照亮后来的人。**

### 备选方案 B：**偏底部电影字幕式**（V0.6）

- 标题 y=582；结语 y=622、653。优点是星座下方留白宽裕，缺点是文字重心偏低，在手机观看时容易变成独立的页脚，而不是星座叙事的情绪收束。
- **结论：推荐 A。** A 的文本整体进入中下部，既与上方星座形成完整构图，又给画面底部保留呼吸空间。字距和宋体在实际 iPhone Safari 上需继续肉眼检查，尤其要避免“花哨的古风标题”。

## 四、色彩方向：Muted Celestial / 克制星光

这一版应避免国风符号化和过饱和荧光。建议背景与轨迹采用更低饱和的冷色，核心亲情人物采用小范围暖色点缀。

| 视觉语义 | 色值 / 不透明度 | 设计理由 |
|---|---|---|
| 宇宙底色 | `#050A15` | 接近黑的深蓝，安静、没有纯黑死板感 |
| 星云中间层 | `#0C1727` → `#08101E` | 明度极低，退到背景，不制造第二视觉主体 |
| 我 | `#DEC98B` | 一点点暖金，与整个画面形成主角焦点 |
| 伴侣 | `#D8B0C9` | 柔和的灰玫瑰，贴近金色而不竞争 |
| 孩子 | `#9FCBC5` | 清淡青绿，与伴侣和“我”形成适度区分 |
| 母亲 | `#D9A6AD` | 灰粉偏暖，与伴侣区分微小但可辨 |
| 父亲 | `#A6BED7` | 安静的雾蓝 |
| 外婆 | `#B7A9C9` | 柔和灰紫 |
| 爷爷 | `#D1D8E0` | 中性冷白 |
| 朋友/同窗/同事 | 灰青、石蓝、灰紫、褐金系列 | 功能区分色，但明度不超过主角 |
| 星座连线 | `#ABB9D1`，最高约22%不透明度 | 低对比细线，视觉上属于“记忆关系”而非新主角 |
| 结尾主标题 | `#EBEDEC` | 柔白而非高纯度白色 |
| 结语 | 近 `#C8D2DC`，最高约83%不透明度 | 一层明显的次级视觉结构 |

**原则：** 人物色彩服务识别，不承担身份刻板印象；颜色不代表性别、社会角色的价值高低，也不通过颜色区分“活着”和“去世”，后者由运动状态表达。
