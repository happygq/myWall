# 《人间一程》中文人物与结尾文案设计 V0.1

## 设计原则

中文化的是人物关系称谓和最后的情绪表达，不改变原作的极简动态图形语言。人物仍然是小光点，关系仍由相对距离表达；不增加头像、亲属关系连线或额外装饰。

## 人物体系建议

### 核心家庭

| 原作角色 | 中文称谓 | 设计理由 |
|---|---|---|
| Me | **我** | 不预设主角性别，也不使用丈夫/妻子等身份 |
| Wife | **伴侣** | 不预设伴侣性别，表达长期同行关系 |
| Son | **孩子** | 单个子女时最自然、温暖且不标示性别 |
| Mom | **母** | 简洁，适合画面中的短标签 |
| Dad | **父** | 与“母”构成对称 |
| Grandma | **祖母** | 默认展示称谓；若明确为母系，可用“外婆”或“外祖母” |
| Grandpa | **祖父** | 默认展示称谓；若明确为母系，可用“外公”或“外祖父” |

“祖母/祖父”仅作为默认展示名，实际家庭故事可按亲属支系替换为“奶奶/爷爷”或“外婆/外公”。不应在没有人物背景时擅自假定是哪一侧祖辈。

### 人生相遇者

| 原作角色 | 中文称谓 | 说明 |
|---|---|---|
| Grade school friend | **小学同学** | 童年阶段的学校相遇 |
| Childhood friend | **发小** | 从童年延续的熟悉关系 |
| First love | **初恋** | 保留原作的情感节点 |
| High school friend | **高中同窗** | 青少年阶段的同行者 |
| College friend | **大学同学** | 成年初期形成的友谊，不额外假定亲密程度 |
| Coworker | **同事** | 工作阶段的相遇 |

可选角色（不放进第一版固定时间线）：**恩师、知己、旅伴、旧友**。这些称谓可作为用户自定义角色，不应为了丰富画面而强行加入。

### 子女称谓规则

- 单个孩子：统一使用 **孩子**，不使用“儿子/女儿”。
- 多个孩子：优先使用本人名字；如果需要匿名，可用“孩子一 / 孩子二”或“长子 / 长女”（仅在明确希望标示性别时）。
- 不建议单独使用“子女”作为一个人的标签，因为“子女”通常是集合称谓。

## 视觉与关系规则

1. “我”是横向位置的中心锚点。
2. “伴侣”与“我”保持最近的长期关系距离。
3. “孩子”在出生时出现在“我”和“伴侣”附近；出生光点仅做一次缓慢、柔和的呼吸式闪亮。
4. 孩子逐渐独立，到“我”约 60 岁时与“我”保持约 110 个画布坐标单位的距离。
5. 父母、祖辈仍按各自生命阶段同行或离去。
6. 人生相遇者优先落在“我”附近的可用位置，但不得与现有光点重合；入场与离场允许短暂离开共同年龄水平线，完成弧线后回到共同时间线。
7. 不为中文版本增加水墨、山水、书法边框等装饰。中文化应主要体现在称谓、叙事和结尾文字。

## 结尾文案

### 推荐主版本

> 人间一程  
> 有人陪你走过一程，  
> 有人留在你的星空。  
> 生命，仍向远方。

理由：保留原作“有人陪你走一段，有人永远留在你的天空”的核心意境，同时以最后一句呼应孩子穿越星座、继续前行的画面。文字克制，不替观众解释过多。

### 备选版本（更贴近原作直译）

> 人生如旅。  
> 有人陪你走过一程，  
> 有人永远留在你的星空。

这个版本更接近原作，但没有直接点出最后一代继续前行的含义，建议作为字幕极简版备用。

### 备选版本（更具中文诗意）

> 人生如旅，聚散有时。  
> 有人同行一程，  
> 有人化作星辰。  
> 而后来的人，仍将远行。

这个版本更文学化，但“化作星辰”略显直白，且“后来的人”不如“生命”自然。建议优先采用主版本。

## 结尾呈现建议

不要在孩子穿越星座的过程中提前出现文案。先让孩子的光点和尾迹完整穿过星座，留出短暂的安静，再淡入四行文字。文字应小而克制，保持原作最后字幕的留白与情绪余韵。
