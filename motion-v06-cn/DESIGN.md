# 《人间一程》 Motion Study V0.6 — 参考复核与中文语境

**参考**：2026-10-30 用户上传的 82 秒 Instagram 录屏及原作截屏。当前为独立复刻研究，不是原作者工程文件。

## 复核记录

- **侧边人物入场**（录屏约 5–11 秒、15–28 秒）：人物从画面左右两侧沿宽大而连续的弧线进入；并入主角的当前年龄水平线后，调整为轻微飘动的近垂直轨迹。相遇后的人际距离相对亲密，不以关系连接线表达。
- **Son 出生**（约 32–34 秒）：Son 出现在伴侣与 Me 之间的狭小空间，光点由弱到强地显现，效果轻微；没有明显爆炸、环形冲击波或大量粒子。录屏无法准确量化具体闪烁周期，因此本作只采用一次缓慢光晕呼吸作为近似。
- **离场**：普通同行者向侧边滑离；逝世人物停止现实尾迹并缓慢升空成星。最终由亲人星辰构成星座，孩子沿原有垂直轨迹继续走向远方。保留 V0.5 的 110 画布单位独立间距与连续性。

## V0.6 技术改动

1. **同行位置**：仅调整侧边关系角色的停靠坐标，原有左右入场/离场方向、入退场时点、持续时间、曲线公式不变。对已经完成入场的角色，进一步收紧横向微动幅度，以降低人物碰撞风险。
2. **出生光点**：Son 出生后在约 1.45 个叙事时间单位内产生一次缓慢亮度呼吸（轻微增大光点尺寸及局部光晕）；未新增轨迹、环形波纹或粒子。
3. **中文/英文**：增加一键切换。采用同一动画数据及状态机，语言切换仅更改标签与结尾文字。
4. **结尾**：中文试写版本；英文文本保留便于忠实对照原作。

## 建议的人物命名

| 内部角色 | 中文显示 | 设计理由 |
|---|---|---|
| Me | 我 | 不设定主角性别 |
| Wife | 伴侣 | 不将核心伴侣限定为妻或夫 |
| Son | 孩子 | 同时兼容子/女；从出生到成年始终保持亲子视角 |
| Mom / Dad | 母亲 / 父亲 | 识别明确、自然且简洁 |
| Grandma / Grandpa | 外婆 / 爷爷 | 作为样例的两位祖辈，可在个性化配置中替换为奶奶/外公等 |
| Grade school friend | 小学同窗 | 一段童年同路 |
| Childhood friend | 发小 | 中国口语中独特的童年亲密关系 |
| First love | 初恋 | 不预设对方性别 |
| High school friend | 高中同窗 | 与小学同窗区分时段 |
| College friend | 大学同窗 | 与其他同窗区分时段 |
| Coworker | 同事 | 职业关系，不限定性别 |

注：身份在真实人生中有个体差异；上述设定是虚构剧本的工作名称，不用于推断用户的实际经历。

## 结尾文案（当前推荐）

> **人间一程**  
> 有人陪你走过一段路。  
> 有人化作星辰，照亮后来的人。

理由：前一句对应同行与聚散，后一句同时照顾逝者化星、孩子继续前进的画面。保持极简，文字直到结尾星座形成后才出现。

备用：

> **人生如旅**  
> 有人同行一程，  
> 有人长留星河。

此备用文案更短，但对“孩子继续向前”的呼应略弱。建议暂以第一版为准。

## 验收与后续

- 浏览器脚本启动、播放/暂停、进度拖动、语言切换、跳结尾可用。
- 人物均在主角的共同当前年龄线上同行（除已离世角色，以及视觉透视转换的终章）。
- 抽样扫描 0–45 岁：除主角与孩子的家庭路径交错外，同行点间无 16 单位以下重叠。
- 下一轮集中验证手机端观看及两处事件的观感，避免未经评审新增装饰特效。
